# رصد بازار

رصد خودکار خبر، قیمت و تقویم اقتصادی برای **فارکس، طلا، نفت و ارز دیجیتال**، با تحلیل هوش مصنوعی به فارسی.
ایده و ساختار کلی از پروژه‌ی [rasadai](https://github.com/itsyebekhe/rasadai) گرفته شده، ولی کد از نو برای بازارهای مالی نوشته شده است.

> ⚠️ این ابزار توصیه‌ی سرمایه‌گذاری نمی‌دهد. تحلیل‌ها خودکارند و ممکن است اشتباه باشند.

## چه کار می‌کند

هر ۱۵ دقیقه یک بار:

1. **قیمت** ۱۲ دارایی را می‌گیرد (بیت‌کوین، اتریوم، سولانا، ریپل، BNB، یورو/دلار، پوند/دلار، دلار/ین، شاخص دلار، طلا، نفت برنت، تتر/تومان) به‌همراه تاریخچه‌ی ساعتی ۷ روز.
2. **تقویم اقتصادی** هفته را از Forex Factory می‌گیرد.
3. **خبرهای تازه** را از فیدهای کریپتو، فارکس و بانک‌های مرکزی جمع می‌کند و تکراری‌ها را حذف می‌کند.
4. با **Gemini** هر خبر را به فارسی ترجمه و خلاصه می‌کند و می‌گوید روی کدام دارایی، در چه جهتی (صعودی، نزولی، خنثی) و با چه اطمینانی اثر دارد.
5. **دقت خودش را می‌سنجد:** قیمت لحظه‌ی ثبت خبر را نگه می‌دارد و ۱، ۴ و ۲۴ ساعت بعد مقایسه می‌کند که جهت پیش‌بینی‌شده درست بوده یا نه.
6. خبرهای پرتأثیر و رویدادهای مهم تقویم را به **کانال تلگرام** می‌فرستد.

نتیجه در یک صفحه‌ی وب (`index.html`) با نمودار قیمت و نشانه‌ی خبرها نمایش داده می‌شود.

## اجرای محلی

به پایتون ۳.۱۱ یا بالاتر نیاز دارید.

```bash
pip install -r requirements.txt
```

```bash
python main.py
```

```bash
python -m http.server 8765
```

بعد `http://localhost:8765` را باز کنید. (باز کردن مستقیم فایل `index.html` کار نمی‌کند، چون مرورگر اجازه‌ی خواندن فایل‌های داده را نمی‌دهد.)

برای فعال‌شدن تحلیل هوش مصنوعی، فایل `.env.example` را به نام `.env` کپی کنید و کلید Gemini را در آن بگذارید. کلید رایگان را از [Google AI Studio](https://aistudio.google.com/apikey) بگیرید.
بدون کلید هم برنامه اجرا می‌شود، ولی خبرها فقط با کلیدواژه برچسب می‌خورند و ترجمه، جهت و سنجش دقت ندارند.

تست سریع (بدون اینترنت):

```bash
python tests/test_smoke.py
```

## راه‌اندازی رایگان روی گیت‌هاب

1. یک ریپوی **عمومی** بسازید و این پوشه را در آن push کنید.
2. در `Settings > Secrets and variables > Actions` این secretها را اضافه کنید:
   - `GEMINI_API_KEY` (لازم برای تحلیل)
   - `TG_BOT_TOKEN` و `TG_CHANNEL_ID` (اختیاری، برای تلگرام)
3. در `Settings > Pages`، گزینه‌ی `Deploy from a branch` و شاخه‌ی `main` (پوشه‌ی `/root`) را انتخاب کنید.
4. در تب `Actions`، گردش‌کار `Update market radar` را یک بار دستی اجرا کنید. بعد از آن خودش هر ۱۵ دقیقه اجرا می‌شود.

صفحه در آدرس `https://<نام-کاربری>.github.io/<نام-ریپو>/` در دسترس خواهد بود.

### تلگرام

با [@BotFather](https://t.me/BotFather) یک ربات بسازید، آن را ادمین کانالتان کنید، و توکن ربات و شناسه‌ی کانال (مثلاً `@my_channel`) را در secretها بگذارید.
خبرهایی با تأثیر ۷ به بالا و رویدادهای مهم تقویم (۳۰ دقیقه قبل از شروع) فرستاده می‌شوند.

## ساختار

| فایل | کار |
|---|---|
| `main.py` | یک اجرای کامل همه‌ی مراحل |
| `rasad/config.py` | فهرست دارایی‌ها، فیدهای خبر و همه‌ی پارامترها |
| `rasad/prices.py` | قیمت‌ها (Binance با پشتیبان OKX، Yahoo Finance، Wallex) |
| `rasad/news.py` | خواندن فیدهای RSS و حذف تکراری‌ها |
| `rasad/ai.py` | تحلیل با Gemini و اعتبارسنجی خروجی |
| `rasad/outcomes.py` | سنجش دقت پیش‌بینی‌ها |
| `rasad/econ_calendar.py` | تقویم اقتصادی |
| `rasad/telegram.py` | هشدار تلگرام |
| `index.html` | داشبورد |
| `data/` | خروجی‌ها (JSON) |

برای اضافه‌کردن دارایی یا منبع خبر، فقط `rasad/config.py` را ویرایش کنید.

## سنجش دقت چطور حساب می‌شود

- فقط خبرهایی شمرده می‌شوند که هوش مصنوعی برایشان جهت **صعودی** یا **نزولی** داده است.
- قیمت مبنا، قیمت دارایی در لحظه‌ای است که سیستم خبر را ثبت کرده (نه لحظه‌ی انتشار خبر)؛ یعنی همان لحظه‌ای که شما هشدار را می‌بینید.
- اگر قیمت در جهت پیش‌بینی‌شده دست‌کم ۰٫۰۵٪ حرکت کرده باشد «درست»، اگر در جهت مخالف «غلط»، و در غیر این صورت «بی‌تغییر» حساب می‌شود.
- نرخ درستیِ نزدیک به ۵۰٪ یعنی پیش‌بینی‌ها ارزش خاصی نداشته‌اند. قبل از اعتماد به این عددها صبر کنید تا دست‌کم چند صد نتیجه جمع شود.

## محدودیت‌های این نسخه

- **لحظه‌ای نیست.** فاصله‌ی اجراها ۱۵ دقیقه است و زمان‌بندی گیت‌هاب گاهی دیرتر اجرا می‌شود. برای هشدار لحظه‌ای باید روی یک سرور مجازی اجرا شود.
- **فقط خلاصه‌ی فید خوانده می‌شود**، نه متن کامل خبر.
- **داده‌ها در خود ریپو ذخیره می‌شوند**، پس تاریخچه‌ی git به‌مرور بزرگ می‌شود. برای استفاده‌ی طولانی، داده‌ها را به پایگاه‌داده (مثلاً SQLite یا Supabase) منتقل کنید.
- منبع قیمت فارکس و طلا (Yahoo Finance) غیررسمی است و ممکن است گاهی در دسترس نباشد؛ در این حالت آخرین قیمت با برچسب «به‌روز نشده» می‌ماند.
- بعضی فیدها (مثل CoinDesk) از بعضی آی‌پی‌ها جواب نمی‌دهند؛ برنامه از آن‌ها رد می‌شود و با بقیه ادامه می‌دهد.
- قیمت طلا و نفت از بازار آتی است (`GC=F` و `BZ=F`) و با قیمت نقدی کمی فرق دارد.
